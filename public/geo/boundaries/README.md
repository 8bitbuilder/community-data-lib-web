# Census boundary files for /maps

Generated by `npm run geo:boundaries` (`scripts/build-geo-boundaries.mjs`). Do not edit by hand.

| File | Source | Features | Size |
|---|---|---|---|
| `us-states-2025-20m.geojson` | https://www2.census.gov/geo/tiger/GENZ2025/shp/cb_2025_us_state_20m.zip | 51 | 261 KB |
| `us-counties-2025-20m.geojson` | https://www2.census.gov/geo/tiger/GENZ2025/shp/cb_2025_us_county_20m.zip | 3144 | 1494 KB |

- **Source**: U.S. Census Bureau cartographic boundary files (generalized from TIGER/Line for display),
  https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html
- **Vintage**: 2025
- **Resolution**: 1:20,000,000 (`20m`)
- **Processing** (mapshaper 0.6.121): reprojected from NAD83 to WGS84; kept the 50 states and DC
  (Puerto Rico and the island areas are left out); fields reduced to `GEOID`, `name` and `state` (USPS code);
  feature `id` = GEOID; Aleutian longitudes past 180° shifted by −360; coordinates rounded to 0.0001°.
- **Simplification**: none beyond the Census generalization.
- **Generated**: 2026-10-20

The map's coverage comes from dataset FIPS codes, not from this geometry; the build fails if a
dataset's coverage FIPS is not in these files.
